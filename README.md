# Кузница Героя: Капибара-Кузнец (Idle Merge RPG)

Полностью автономная HTML5-игра для Яндекс Игр: без эмодзи (вся графика — процедурный SVG),
без аудиофайлов (звук синтезируется через Web Audio API), без внешних зависимостей кроме SDK Яндекса.

## Структура

```
index.html        — каркас страницы + подключение SDK и скриптов
css/style.css     — адаптивный one-screen layout (35% арена / 40% кузница / 25% вкладки)
js/i18n.js        — локализация RU/EN: 50 имён мечей, 15 монстров, 10 боссов, 10 биомов, весь UI
js/art.js         — ArtGenerator: процедурные SVG (оружие 12 материалов, монстры, капибара,
                    питомцы, иконки, 10 анимированных биомов, дрон, колесо фортуны)
js/audio.js       — SoundEngine: синтез всех SFX + фоновый chiptune/lofi-луп, mute
js/sdk.js         — YandexSDKManager: init, LoadingAPI.ready, язык, Rewarded/Interstitial
                    (кулдаун 180с), player.setData, пауза по visibilitychange, mock-режим
js/game.js        — баланс (Damage/HP/Gold формулы), бой, кузница, апгрейды, питомцы,
                    престиж, квесты, колесо, оффлайн-доход, автосейв 10с
js/ui.js          — рендер, drag&drop (мышь+тач), частицы на canvas, вкладки, модалки
js/main.js        — порядок запуска
```

## Локальный запуск

Открыть `index.html` в браузере (SDK не найдётся — включится mock-режим с имитацией
рекламы таймером-оверлеем 2 секунды). Проще всего через локальный сервер:

```
npx serve .
# или
python -m http.server
```

## Сборка для Яндекс Игр

1. Заархивировать содержимое папки в `zip` так, чтобы `index.html` лежал в корне архива.
2. Загрузить черновик в Консоль разработчика Яндекс Игр. На вкладке «Черновик» в поле
   **«Игра переведена на»** указать ровно `Русский` и `English` (это языки игры).
3. Чек-лист модерации, закрытый игрой:
   - **п. 2.14 (язык)**: язык берётся из `ysdk.environment.i18n.lang` сразу после `YaGames.init()`,
     до первого рендера (первый кадр скрыт через `body.boot`); резервный набор — RU для
     ru/be/kk/uk/uz, EN для всех остальных; кэш не перекрывает SDK (SDK-mocks работают);
     локальная проверка языка без SDK: `index.html?lang=en`;
   - `ysdk.features.LoadingAPI.ready()` вызывается после первой отрисовки (js/ui.js → onLoaded);
   - при открытии рекламы и `visibilitychange` игровой цикл ставится на паузу, а
     AudioContext suspends (js/sdk.js + js/game.js → setPaused);
   - Rewarded-видео для всех бонусов, Interstitial не чаще 1 раза в 180 секунд;
   - автосохранение каждые 10 секунд, при слиянии и сворачивании: localStorage + `player.setData`;
   - оффлайн-доход с кнопками «Забрать» / «Забрать x2 за рекламу»;
   - нет эмодзи, внешних ссылок и пользовательского контента.
4. Самопроверка языка: открыть игру с параметром `?debug-mode=16` на площадке Яндекса —
   индикатор «I18N is used» должен быть зелёным на старте; через **SDK mocks** в панели
   проверить оба языка.

## Управление

- **Наковальня** — клики ускоряют ковку (0.5с за клик).
- **Сетка** — перетащи одинаковые мечи друг на друга (или двойной клик/тап) для слияния.
  Долгое удержание меча — продажа. Перетащи меч на слот «В лапах капибары» — экипировка.
- Каждая 5-я волна — босс с таймером 30 секунд; не успел — откат на волну назад.
- Престиж доступен с 30-й волны (вкладка «Престиж»).
